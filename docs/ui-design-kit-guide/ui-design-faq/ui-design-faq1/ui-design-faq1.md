# 怎么获取layeredDrawableDescriptor对象信息？

应用配置的图标和名称信息，可以通过[resourceManager.getDrawableDescriptor](/ref/localization-api/localization-arkts/js-apis-resource-manager/js-apis-resource-manager#getdrawabledescriptor10)获取。
