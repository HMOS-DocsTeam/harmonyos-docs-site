# 开发实况窗须知

当前实况窗场景请参见[实况窗支持对接的场景](/live-view-kit-guide/liveview-introduction#实况窗支持对接的场景)。针对所有开放的场景，我们为开发者提供了实况窗[场景节点设计参考](/live-view-kit-guide/liveview-design-formula#场景节点设计要求)，开发者可以根据参考设计场景内节点的数量与内容。

![](../../../images/925080df/notice_3.0-zh-cn.png) 

应用发送的实况窗需遵循《[实况窗设计规范](/live-view-kit-guide/liveview-design-formula)》，不符合设计规范的方案将不被予以开通正式权限。同时若应用实况窗上线后出现违反实况窗设计规范的行为，将被视为[违规](/live-view-kit-guide/liveview-introduction#违规处罚)。
