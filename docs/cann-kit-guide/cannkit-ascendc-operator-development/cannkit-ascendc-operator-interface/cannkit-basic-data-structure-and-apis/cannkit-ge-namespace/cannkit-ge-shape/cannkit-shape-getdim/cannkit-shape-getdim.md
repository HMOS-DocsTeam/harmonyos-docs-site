# GetDim

## 函数功能

获取Shape第idx维的长度。

## 函数原型

```
int64_t GetDim(size_t idx) const;
```

## 参数说明

| 参数名 | 输入/输出 | 描述 |
| --- | --- | --- |
| idx | 输入 | 维度索引，索引从0开始。 |

## 返回值

| 类型 | 描述 |
| --- | --- |
| int64\_t | 第idx维的长度。 |

## 异常处理

无

## 约束说明

无
