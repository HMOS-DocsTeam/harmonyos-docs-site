# SetUnknownDimNumShape

## 函数功能

设置tensor的shape为\{-2\}，用来表示tensor是完全未知的。

## 函数原型

```
graphStatus SetUnknownDimNumShape();
```

## 参数说明

无

## 返回值

| 类型 | 描述 |
| --- | --- |
| graphStatus | 函数执行结果。执行成功，则该值为GRAPH\_SUCCESS(即0)，其他值则为执行失败。 |

## 异常处理

无

## 约束说明

无
