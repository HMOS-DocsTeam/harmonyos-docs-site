# ClearChangedResourceKeys

## 函数功能

一般由框架调用。

当变化了的资源触发重新推导之后，需要调用该接口清除inference\_context中保存的变化了的资源标识。

## 函数原型

```
void ClearChangedResourceKeys()
```

## 参数说明

无

## 返回值

无

## 约束说明

无
