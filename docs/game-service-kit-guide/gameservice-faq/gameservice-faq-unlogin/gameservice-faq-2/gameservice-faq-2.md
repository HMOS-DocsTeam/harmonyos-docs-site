# 游戏官方账号图标大小是多少？

游戏官方账号ICON大小总和不超过35KB。若超过35KB，调用[unionLogin](/ref/game-service-api/gameservice-arkts/gameservice-gameplayer/gameservice-gameplayer#gameplayerunionlogin)接口时，会出现[1002000001](/ref/game-service-api/gameservice-arkts/gameservice-error-code/gameservice-error-code#section1002000001-游戏内部通用错误)错误码。
