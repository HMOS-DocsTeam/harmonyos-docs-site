# 数字商品服务中订单订购状态有哪些？

1. 订阅型商品的订阅状态，请查看[订阅状态（status）](/ref/iap-api/iap-rest/iap-query-subscription-status/iap-query-subscription-status#subscriptionstatus)。
2. 消耗型/非消耗型商品，请查看[发货状态（finishStatus）和是否撤销的状态（purchaseOrderRevocationReasonCode）](/ref/iap-api/iap-rest/iap-server-data-model/iap-server-data-model#purchaseorderpayload)。
