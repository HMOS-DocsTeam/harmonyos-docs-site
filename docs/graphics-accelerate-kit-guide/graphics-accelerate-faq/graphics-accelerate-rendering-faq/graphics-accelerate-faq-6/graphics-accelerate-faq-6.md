# Kit支持的设备类型有哪些？

Kit支持的设备类型请参见[支持的设备](/graphics-accelerate-kit-guide/graphics-accelerate-introduction#支持的设备)。同时，您可以通过调用[canIUse()](/ref/common-basic-c/common-basic-module/init/init#caniuse)接口并传入[SystemCapability.GraphicsGame.RenderAccelerate](/ref/graphics-accelerate-api/graphics_accelerate_c_api/total/files/abr__gles_8h/abr__gles_8h)进行设备类型适配查询。
