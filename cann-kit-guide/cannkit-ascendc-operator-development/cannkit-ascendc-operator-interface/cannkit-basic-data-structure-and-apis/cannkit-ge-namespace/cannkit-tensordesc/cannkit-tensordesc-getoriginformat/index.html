GetOriginFormat

函数功能​

获取TensorDesc所描述Tensor的原始Format。

该Format是指原始网络模型的Format。

函数原型​

Format GetOriginFormat() const;

参数说明​

无

返回值​

类型描述
FormatTensorDesc所描述的Tensor的originFormat信息。 关于Format数据类型的定义，请参见Format。

异常处理​

无

约束说明​

无
