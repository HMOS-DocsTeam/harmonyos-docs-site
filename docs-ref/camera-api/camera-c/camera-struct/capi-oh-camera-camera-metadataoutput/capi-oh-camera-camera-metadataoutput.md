# Camera\_MetadataOutput

```
typedef struct Camera_MetadataOutput Camera_MetadataOutput
```

## 概述

元数据输出对象。

可以使用[OH\_CameraManager\_CreateMetadataOutput](/ref/camera-api/camera-c/camera-headerfile/capi-camera-manager-h/capi-camera-manager-h#oh_cameramanager_createmetadataoutput)方法与OH\_CameraManager\_CreateMetadataOutputWithObjectTypes方法（从API version 23开始支持）创建指针。

****起始版本：**** 11

****相关模块：**** [OH\_Camera](/ref/camera-api/camera-c/camera-module/capi-oh-camera/capi-oh-camera)
