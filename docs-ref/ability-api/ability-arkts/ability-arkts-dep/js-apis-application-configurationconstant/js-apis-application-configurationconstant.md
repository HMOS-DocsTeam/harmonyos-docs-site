# @ohos.application.ConfigurationConstant (ConfigurationConstant)

ConfigurationConstant模块提供配置信息枚举值定义的能力。

![](../../../../images/3b525d4a/note_3.0-zh-cn.png) 

本模块首批接口从API version 8开始支持，从API version 9废弃，替换模块为[@ohos.app.ability.ConfigurationConstant (ConfigurationConstant)](/ref/ability-api/ability-arkts/both-models/js-apis-app-ability-configurationconstant/js-apis-app-ability-configurationconstant)。后续版本的新增接口，采用上角标单独标记接口的起始版本。

## 导入模块

```
import ConfigurationConstant from '@ohos.application.ConfigurationConstant';
```

## ColorMode

表示颜色模式的枚举。

****系统能力****：SystemCapability.Ability.AbilityBase

| 名称 | 值 | 说明 |
| --- | --- | --- |
| COLOR\_MODE\_NOT\_SET | -1 | 未设置颜色模式。 |
| COLOR\_MODE\_DARK | 0 | 深色模式。 |
| COLOR\_MODE\_LIGHT | 1 | 浅色模式。 |
