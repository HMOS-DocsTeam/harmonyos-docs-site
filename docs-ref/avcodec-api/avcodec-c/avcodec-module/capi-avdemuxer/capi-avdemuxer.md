# AVDemuxer

## 概述

AVDemuxer模块提供从媒体文件码流中提取[sample](/avcodec-kit/file-muxing-demuxing/audio-video-demuxer)的接口。

对应的开发指南及样例可参考[媒体数据解析](/avcodec-kit/file-muxing-demuxing/audio-video-demuxer)。

****系统能力：**** SystemCapability.Multimedia.Media.Spliter

****起始版本：**** 10
