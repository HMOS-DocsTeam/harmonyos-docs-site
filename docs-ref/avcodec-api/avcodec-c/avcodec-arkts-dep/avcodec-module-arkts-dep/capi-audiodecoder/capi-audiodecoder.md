# AudioDecoder

## 概述

AudioDecoder模块提供用于音频解码功能的函数。

****系统能力：**** SystemCapability.Multimedia.Media.AudioDecoder

****起始版本：**** 9

****废弃版本：**** 11

****替代建议：**** 当前模块下的接口均已废弃，开发者可使用[AudioCodec](/ref/avcodec-api/avcodec-c/avcodec-module/capi-audiocodec/capi-audiocodec)完成对应功能开发，单个接口的替代关系可查阅具体的接口说明。
