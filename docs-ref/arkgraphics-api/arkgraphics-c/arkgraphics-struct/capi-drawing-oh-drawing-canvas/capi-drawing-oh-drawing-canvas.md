# OH\_Drawing\_Canvas

```
typedef struct OH_Drawing_Canvas OH_Drawing_Canvas
```

## 概述

定义为一块矩形的画布，可以结合画笔和画刷在上面绘制各种形状、图片和文字。

****起始版本：**** 8

****相关模块：**** [Drawing](/ref/arkgraphics-api/arkgraphics-c/arkgraphics-module/capi-drawing/capi-drawing)
