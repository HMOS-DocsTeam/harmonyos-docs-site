# WhitePointArray

```
typedef struct WhitePointArray {...} WhitePointArray
```

## 概述

提供白点数组结构体，白点是指在当前色域中表示白色的坐标。

****起始版本：**** 13

****相关模块：**** [NativeColorSpaceManager](/ref/arkgraphics-api/arkgraphics-c/arkgraphics-module/capi-nativecolorspacemanager/capi-nativecolorspacemanager)
