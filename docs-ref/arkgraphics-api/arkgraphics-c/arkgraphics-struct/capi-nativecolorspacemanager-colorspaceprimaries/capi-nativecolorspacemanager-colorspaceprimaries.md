# ColorSpacePrimaries

```
typedef struct {...} ColorSpacePrimaries
```

## 概述

提供色彩原色结构体声明。

****起始版本：**** 13

****相关模块：**** [NativeColorSpaceManager](/ref/arkgraphics-api/arkgraphics-c/arkgraphics-module/capi-nativecolorspacemanager/capi-nativecolorspacemanager)

****所在头文件：**** [native\_color\_space\_manager.h](/ref/arkgraphics-api/arkgraphics-c/arkgraphics-headerfile/capi-native-color-space-manager-h/capi-native-color-space-manager-h)

### 成员变量

| 名称 | 描述 |

| float rY | 红色的y轴坐标值。 |

| float gY | 绿色的y轴坐标值。 |
| float bX | 蓝色的x轴坐标值。 |
| float bY | 蓝色的y轴坐标值。 |
| float wX | 白点的x轴坐标值。 |
| float wY | 白点的y轴坐标值。 |
