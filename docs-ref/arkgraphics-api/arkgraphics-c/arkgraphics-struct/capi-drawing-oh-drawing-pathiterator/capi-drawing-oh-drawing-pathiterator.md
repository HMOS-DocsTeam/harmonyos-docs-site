# OH\_Drawing\_PathIterator

```
typedef struct OH_Drawing_PathIterator OH_Drawing_PathIterator
```

## 概述

定义为路径操作迭代器，可通过遍历迭代器读取path的操作指令。

****起始版本：**** 23
