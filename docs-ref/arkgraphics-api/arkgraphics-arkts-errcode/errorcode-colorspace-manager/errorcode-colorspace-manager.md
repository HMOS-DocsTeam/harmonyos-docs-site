# 色彩管理错误码

![](../../../images/9f1f3901/note_3.0-zh-cn.png) 

以下仅介绍本模块特有错误码，通用错误码请参考[通用错误码说明文档](/ref/errorcode-universal/errorcode-universal)。

## 18600001 参数值异常

****错误信息****

The parameter value is abnormal.

****错误描述****

当参数值不符合接口调用要求时，系统会报此错误码。

****可能原因****

参数值超出接口调用范围会报错，如枚举值超出定义范围。

****处理步骤****

在定义接口参数前，确保参数值符合接口参数要求。
