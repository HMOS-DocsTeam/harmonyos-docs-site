# SOTER

![](../../../../../images/b2218e19/note_3.0-zh-cn.png) 

以下仅介绍本模块特有错误码，通用错误码请参见[通用错误码](/ref/errorcode-universal/errorcode-universal)。

## 1014500001 服务异常

****错误信息****

The service is abnormal.

****错误描述****

SOTER服务异常时，系统会产生此错误码。

****可能原因****

SOTER服务异常。

****处理步骤****

1. 检查网络状况。
2. 重启系统。
