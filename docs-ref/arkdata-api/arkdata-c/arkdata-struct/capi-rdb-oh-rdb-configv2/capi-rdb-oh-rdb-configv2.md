# OH\_Rdb\_ConfigV2

```
typedef struct OH_Rdb_ConfigV2 OH_Rdb_ConfigV2
```

## 概述

管理关系数据库配置，与[OH\_Rdb\_Config](/ref/arkdata-api/arkdata-c/arkdata-struct/capi-rdb-oh-rdb-config/capi-rdb-oh-rdb-config)的区别是该结构体成员变量不对外暴露，使用一系列方法配置该结构体的属性，支持向量数据库。

****起始版本：**** 14

****相关模块：**** [RDB](/ref/arkdata-api/arkdata-c/arkdata-module/capi-rdb/capi-rdb)
