# AREngine\_ARFrame

```
typedef struct AREngine_ARFrame AREngine_ARFrame
```

## 概述

定义一个结构体，用于存储AR Engine中捕获的单帧AR图像数据，包含特定时间戳下的相机图像、追踪状态、锚点及AR相关信息。

****起始版本：**** 6.1.0(23)

****相关模块：**** [SpatialRecon](/ref/spatial-recon-api/spatial-recon-c/spatial-recon-module/capi-spatialrecon/capi-spatialrecon)
