# OH\_AVSamplesBuffer

```
typedef struct OH_AVSamplesBuffer OH_AVSamplesBuffer
```

## 概述

LowPowerAVSink输入数据的结构体。应用在收到DataNeeded回调后需要将数据打包装进OH\_AVSamplesBuffer实例中送给对应的lowpower\_avsink。

****起始版本：**** 20

****相关模块：**** [AVSinkBase](/ref/media-api/media-c/media-module/capi-avsinkbase/capi-avsinkbase)

****所在头文件：**** [lowpower\_avsink\_base.h](/ref/media-api/media-c/media-headerfile/capi-lowpower-avsink-base-h/capi-lowpower-avsink-base-h)
