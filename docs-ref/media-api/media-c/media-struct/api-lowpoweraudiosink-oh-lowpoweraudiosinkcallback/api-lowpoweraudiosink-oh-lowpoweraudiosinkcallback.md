# OH\_LowPowerAudioSinkCallback

```
typedef struct OH_LowPowerAudioSinkCallback OH_LowPowerAudioSinkCallback
```

## 概述

包含了LowPowerAudioSink回调函数指针的集合。

应用需注册此实例结构体到[OH\_LowPowerAudioSink](/ref/media-api/media-c/media-struct/capi-lowpoweraudiosink-oh-lowpoweraudiosink/capi-lowpoweraudiosink-oh-lowpoweraudiosink)实例中，并对回调上报的信息进行处理，保证LowPowerAudioSink的正常运行。
