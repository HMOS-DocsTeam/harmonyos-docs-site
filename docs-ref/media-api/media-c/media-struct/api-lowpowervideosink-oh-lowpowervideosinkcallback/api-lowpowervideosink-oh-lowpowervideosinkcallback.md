# OH\_LowPowerVideoSinkCallback

```
typedef struct OH_LowPowerVideoSinkCallback OH_LowPowerVideoSinkCallback
```

## 概述

包含了LowPowerVideoSink回调函数指针的集合。

应用需注册此实例结构体到[OH\_LowPowerVideoSink](/ref/media-api/media-c/media-struct/capi-lowpowervideosink-oh-lowpowervideosink/capi-lowpowervideosink-oh-lowpowervideosink)实例中，并对回调上报的信息进行处理，保证LowPowerVideoSink的正常运行。
