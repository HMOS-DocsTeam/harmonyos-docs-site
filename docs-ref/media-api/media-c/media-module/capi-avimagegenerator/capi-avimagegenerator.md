# AVImageGenerator

## 概述

提供用于从视频资源中获取指定时间点视频帧的API。

根据实际的开发需求，参考对应的开发指南及样例[使用AVImageGenerator获取视频帧(C/C++)](/media-kit/media-kit-dev--c/media-info-c/using-ndk-avimagegenerator-for-video)。

****系统能力：**** SystemCapability.Multimedia.Media.AVImageGenerator

****起始版本：**** 18
