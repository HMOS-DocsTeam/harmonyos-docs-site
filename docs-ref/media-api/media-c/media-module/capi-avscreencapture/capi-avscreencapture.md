# AVScreenCapture

## 概述

开发者可根据实际的开发需求，参考对应的开发指南及样例：

- [使用AVScreenCapture录屏取码流](/media-kit/media-kit-dev--c/media-recording-c/using-avscreencapture-for-buffer/avscreencapture-c-basic-process)
- [使用AVScreenCapture录屏写文件](/media-kit/media-kit-dev--c/media-recording-c/using-avscreencapture-for-file)

****起始版本：**** 10
