# JSVM\_Env\_\_\*

```
typedef struct JSVM_Env__* JSVM_Env
```

## 概述

表示虚拟机特定状态的上下文环境，需要在调用native函数时作为参数传递，并且传递给后续任何的JSVM-API嵌套调用。
