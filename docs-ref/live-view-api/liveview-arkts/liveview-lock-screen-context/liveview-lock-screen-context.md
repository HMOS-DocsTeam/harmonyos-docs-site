# LiveViewLockScreenExtensionContext

LiveViewLockScreenExtensionAbility的上下文环境，继承自[ExtensionContext。](/ref/ability-api/ability-arkts/ability-api-interface-depend/ability-arkts-application/js-apis-inner-application-extensioncontext/js-apis-inner-application-extensioncontext)

****起始版本：**** 5.0.0(12)

## 导入模块

```
import { LiveViewLockScreenExtensionContext } from '@kit.LiveViewKit';
```

****设备行为差异：**** 该模块在Phone、Tablet中可正常调用，在其他设备类型中无效果。
