# ArkWeb\_ResourceRequest\_

```
typedef struct ArkWeb_ResourceRequest_ ArkWeb_ResourceRequest
```

## 概述

对应内核的一个请求，可以通过OH\_ArkWebResourceRequest\_系列接口获取请求的URL、method、post data以及其他信息。如通过[OH\_ArkWebResourceRequest\_GetUrl](/ref/arkweb-api/arkweb-c/arkweb-headerfile/capi-arkweb-scheme-handler-h/capi-arkweb-scheme-handler-h#oh_arkwebresourcerequest_geturl)获取请求的URL。
