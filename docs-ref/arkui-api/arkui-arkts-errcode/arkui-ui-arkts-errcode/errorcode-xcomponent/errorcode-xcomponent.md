# XComponent组件错误码

![](../../../../images/51299951/note_3.0-zh-cn.png) 

以下仅介绍本模块特有错误码，通用错误码请参考[通用错误码](/ref/errorcode-universal/errorcode-universal)。

## 103501 XComponent状态异常

****错误信息****

XComponent is in invalid state.

****错误描述****

当前XComponent状态异常，方法调用失败。

****可能原因****

参考报错接口的说明。

****处理步骤****

确保XComponent持有的Surface状态正常。
