# ArkUI\_TouchTestInfoItem

```
typedef struct ArkUI_TouchTestInfoItem ArkUI_TouchTestInfoItem
```

## 概述

定义触摸测试信息项。触摸测试信息项包含触摸测试中子组件的信息，可以通过[OH\_ArkUI\_TouchTestInfoItem\_GetXXX](/ref/arkui-api/arkui-c/arkui-headerfile/capi-ui-input-event-h/capi-ui-input-event-h#oh_arkui_touchtestinfoitem_getx)系列接口获取子组件信息。

****起始版本：**** 22

****相关模块：**** [ArkUI\_EventModule](/ref/arkui-api/arkui-c/arkui-module/capi-arkui-eventmodule/capi-arkui-eventmodule)

****所在头文件：**** [ui\_input\_event.h](/ref/arkui-api/arkui-c/arkui-headerfile/capi-ui-input-event-h/capi-ui-input-event-h)
