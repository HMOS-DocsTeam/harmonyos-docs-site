# @ohos.application.NotificationSubscriberExtensionContext (通知订阅扩展上下文)

NotificationSubscriberExtensionContext模块提供通知订阅者扩展能力。

![](../../../images/b5e4d8c2/note_3.0-zh-cn.png) 

本模块首批接口从API version 22开始支持。后续版本的新增接口，采用上角标单独标记接口的起始版本。

本模块接口仅可在Stage模型下使用。

## 导入模块

```
import { NotificationSubscriberExtensionContext } from '@kit.NotificationKit';
```

## NotificationSubscriberExtensionContext

NotificationSubscriberExtensionContext继承自[ExtensionContext](/ref/ability-api/ability-arkts/ability-api-interface-depend/ability-arkts-application/js-apis-inner-application-extensioncontext/js-apis-inner-application-extensioncontext)类，是NotificationSubscriberExtensionAbility的上下文。

****系统能力****：SystemCapability.Notification.Notification
