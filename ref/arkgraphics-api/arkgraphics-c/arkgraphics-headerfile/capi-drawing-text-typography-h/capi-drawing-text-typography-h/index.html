drawing_text_typography.h

概述​

定义绘制模块中排版相关的函数。

引用文件： <native_drawing/drawing_text_typography.h>

库： libnative_drawing.so

系统能力： SystemCapability.Graphic.Graphic2D.NativeDrawing

起始版本： 8

相关模块： Drawing
