healthFields(运动健康数据字段)

本模块提供运动健康数据字段列表。

起始版本： 5.0.0(12)

导入模块​

import { healthStore } from '@kit.HealthServiceKit';

此模块为healthStore子模块，需通过healthStore.healthFields方式使用。
