samplePointHelper(采样数据类型常量)

本模块提供采样数据类型常量及数据模型。

起始版本： 5.0.0(12)

导入模块​

import { healthStore } from '@kit.HealthServiceKit';

此模块为healthStore子模块，需通过healthStore.samplePointHelper方式使用。
