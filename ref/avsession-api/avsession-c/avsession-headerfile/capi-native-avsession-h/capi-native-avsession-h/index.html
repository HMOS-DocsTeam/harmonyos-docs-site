native_avsession.h

概述​

媒体会话定义，可用于设置元数据、播放状态信息等操作。

引用文件： <multimedia/av_session/native_avsession.h>

库： libohavsession.so

系统能力： SystemCapability.Multimedia.AVSession.Core

起始版本： 13

相关模块： OHAVSession

汇总​

结构体​

名称typedef关键字描述
OH_AVSessionOH_AVSession定义播控会话对象。播控会话对象可以使用OH_AVSession_Create方法创建。
OH_AVCastControllerOH_AVCastController声明投播控制器对象。投播控制器对象可以使用OH_AVSession_CreateAVCastController方法创建。
