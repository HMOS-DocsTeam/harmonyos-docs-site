avcodec_audio_channel_layout.h

概述​

音频编解码声道布局枚举的声明。

引用文件： <multimedia/player_framework/avcodec_audio_channel_layout.h>

库： libnative_media_codecbase.so

系统能力： SystemCapability.Multimedia.Media.CodecBase

起始版本： 10

废弃版本： 11

相关模块： CodecBase

汇总​

枚举​

名称描述
AudioChannelSet音频声道数集合，将每一个声道数映射为int64的变量。(API11废弃)
AudioChannelLayout音频声道数类型，将用户申请的解码器输出格式表示为编解码器的声道类型。(API11废弃)
