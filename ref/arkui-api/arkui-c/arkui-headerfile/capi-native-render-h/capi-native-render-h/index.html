native_render.h

概述​

提供NativeRender接口的类型定义。更多详细介绍请参考构建渲染节点。

引用文件： <arkui/native_render.h>

库： libace_ndk.z.so

系统能力： SystemCapability.ArkUI.ArkUI.Full

起始版本： 20

相关模块： ArkUI_RenderNodeUtils

相关示例： NativeRenderNodeSample
