drag_and_drop.h

概述​

提供NativeDrag相关接口定义。

引用文件： <arkui/drag_and_drop.h>

库： libace_ndk.z.so

系统能力： SystemCapability.ArkUI.ArkUI.Full

起始版本： 12

相关模块： ArkUI_NativeModule

相关示例： NativeDragDrop
