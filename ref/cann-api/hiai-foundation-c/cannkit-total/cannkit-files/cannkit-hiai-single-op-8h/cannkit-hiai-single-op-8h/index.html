hiai_single_op.h

概述​

定义CANN Kit单算子接口，用于单算子的创建、计算以及Tensor和Buffer的管理。

引用文件： <CANNKit/hiai_single_op.h>

库： libhiai_foundation.so

系统能力： SystemCapability.AI.HiAIFoundation

起始版本： 5.0.0(12)

相关模块： CANN
