relational_store_error_code.h

概述​

声明关系型数据库（RDB）的错误码信息。

引用文件： <database/rdb/relational_store_error_code.h>

库： libnative_rdb_ndk.z.so

系统能力： SystemCapability.DistributedDataManager.RelationalStore.Core

起始版本： 10

相关模块： RDB

OH_Rdb_ErrCode​

enum OH_Rdb_ErrCode

描述

表示错误码信息。

起始版本： 10
