udmf_meta.h

概述​

声明统一类型数据信息。

引用文件： <database/udmf/udmf_meta.h>

库： libudmf.so

系统能力： SystemCapability.DistributedDataManager.UDMF.Core

起始版本： 12

相关模块： UDMF

汇总​
