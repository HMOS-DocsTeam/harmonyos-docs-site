API错误码

  • 以下仅介绍本模块特有错误码，通用错误码请参考通用错误码。
  • Remote Communication Kit错误码映射关系：1007900000 + curl错误码。Remote Communication Kit常见错误码如下， 更多错误码可参考：curl错误码。

1007900001 不支持的协议​

错误信息

Unsupported protocol.

错误描述

协议版本服务器不支持。

可能原因

传入的协议版本，服务器不支持。

处理步骤
