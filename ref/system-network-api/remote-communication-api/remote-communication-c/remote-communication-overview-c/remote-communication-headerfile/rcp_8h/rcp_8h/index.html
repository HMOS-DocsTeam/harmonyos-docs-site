rcp.h

概述​

声明用于访问远程通信的API。提供基本的函数，结构体和const定义。

引用文件： <RemoteCommunicationKit/rcp.h>

库： librcp_c.so

系统能力： SystemCapability.Collaboration.RemoteCommunication

起始版本： 5.0.0(12)

相关模块： RemoteCommunication
