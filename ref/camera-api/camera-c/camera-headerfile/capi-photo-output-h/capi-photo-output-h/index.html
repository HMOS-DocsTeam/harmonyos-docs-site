photo_output.h

概述​

声明拍照输出概念。

引用文件： <ohcamera/photo_output.h>

库： libohcamera.so

系统能力： SystemCapability.Multimedia.Camera.Core

起始版本： 11

相关模块： OH_Camera

汇总​

结构体​

名称typedef关键字描述
PhotoOutput_CallbacksPhotoOutput_Callbacks拍照输出的回调。
Camera_PhotoOutputCamera_PhotoOutput拍照输出对象。 可以使用OH_CameraManager_CreatePhotoOutput方法创建指针。
