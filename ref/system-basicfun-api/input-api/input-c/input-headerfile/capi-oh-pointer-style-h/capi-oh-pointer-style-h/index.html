oh_pointer_style.h

概述​

鼠标光标的样式。

引用文件： <multimodalinput/oh_pointer_style.h>

库： libohinput.so

系统能力： SystemCapability.MultimodalInput.Input.Core

起始版本： 22

相关模块： input
