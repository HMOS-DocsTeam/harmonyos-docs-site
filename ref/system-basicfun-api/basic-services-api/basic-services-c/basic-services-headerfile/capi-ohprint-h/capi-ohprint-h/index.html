ohprint.h

概述​

声明用于发现和连接打印机、通过打印机打印文件、查询已添加打印机列表及其内部打印机信息等功能的 API。

引用文件： <BasicServicesKit/ohprint.h>

库： libohprint.so

系统能力： SystemCapability.Print.PrintFramework

起始版本： 12

相关模块： OH_Print
