oh_commonevent_support.h

概述​

提供系统定义的公共事件常量。

库： libohcommonevent.so

引用文件： <BasicServicesKit/oh_commonevent_support.h>

系统能力： SystemCapability.Notification.CommonEvent

起始版本： 12

相关模块： OH_CommonEvent
