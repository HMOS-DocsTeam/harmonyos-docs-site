avplayer.h

概述​

定义AVPlayer接口。使用AVPlayer提供的Native API播放媒体源。

引用文件： <multimedia/player_framework/avplayer.h>

库： libavplayer.so

系统能力： SystemCapability.Multimedia.Media.AVPlayer

起始版本： 11

相关模块： AVPlayer

相关示例： AVPlayerNDKVideo
